⭐ THIS WAY OF REINSTALLING IS HIGHLY RECOMMENDED!
WHY IS THIS HIGHLY RECOMMENDED?

The reason this reinstallation is recommended, especially for people with a lot of HWID bans on their PC, is because this reinstallation method changes your SSD/NVMe serials as well. This is an important factor and almost a 99% guaranteed successful spoof.

⚠ Reminder: this is for Intel Only.
ℹ️
Intel RAID Compatibility Haven't checked your compatibility yet? Run the Intel RAID Compatibility Checker to see if your system supports RAID. If it does not, follow the normal reinstallation method instead.
🚨
Before You Begin — Critical Ensure you have never permanently spoofed your motherboard name. If you have, the RAID drivers you download may not match your actual hardware and the installation will fail.
1 Create Windows USB ▼

Microsoft Official Download

https://www.microsoft.com/en-us/software-download/windows10
  1. Download Media Creation Tool from the link above and click "Download Now"
  2. Open the Media Creation Tool as an administrator
  3. Select "Create Installation media (USB Flash drive)"
  4. Use all the recommended options, continue, and wait for it to finish
2 Intel RAID Driver Files ▼
▶ Watch Driver Download Guide
📸
Remember Your Disk Serials! Make a photo of them on your phone — check with Disk serial checker.exe
⚠️
Network Drivers When reinstalling Windows, most modern systems will automatically detect basic Ethernet drivers. In some cases, you may need to manually install them. Download your LAN drivers from your motherboard manufacturer's site (e.g. search "Asus B550 Network drivers") and put them on the USB drive just to be safe.
3 Boot into BIOS & Enable RAID Mode ▼

Restart your computer and enter the BIOS. How to Easily Boot into BIOS ↗ — then navigate to Advanced Mode and locate the SATA/NVMe Storage configuration.

🔍 Finding SATA Mode & M.2 RAID Support — Common Paths

  • Advanced Mode › PCH Storage Configuration (Most Common)
  • Advanced Mode › Storage Configuration
  • Advanced Mode › SA (System Agent) › VMD Controller
  • Advanced Mode › Onboard Devices / Integrated Peripherals
  • Advanced Mode › VMD Controller
4 Configure RAID Settings ▼
💡
VMD Controller Found? If you see a "VMD Controller" option, simply enable it and skip the SATA Mode settings below.
A SATA Mode / Controller → RAID Mode / RST Controlled / Optane Mode
B M.2_1 RST PCIE Storage RAID Support → Enabled / RST Controlled
C M.2_2 RST PCIE Storage RAID Support → Enabled / RST Controlled
ℹ️
The exact names may differ on your motherboard — use common sense!
5 Disable CSM & Enable UEFI ▼

Navigate to the Boot tab and configure:

  • Boot › CSM › Disabled
ℹ️
If you can't find CSM, ensure UEFI is enabled instead.
💾 Save & Exit the BIOS, then re-enter BIOS again!
6 Create RAID Array ▼

Once back in BIOS, navigate to Advanced › Intel(R) RST › Create RAID Volume

  1. Name → Anything of your choice
  2. RAID Level → RAID0 (Stripe)
  3. Select Disks → Choose the disks you want to RAID (can't mix different disk types)
  4. Create Volume → Click to create the array
7 Install Windows ▼

Save & Exit the BIOS and make sure your Windows USB is plugged in. You should see the Windows setup screen.

  1. Change language settings if needed, press Next
  2. If asked for product key, select "I don't have a product key"
  3. Select Windows 10/11 Pro Version — Important!
  4. Accept the TOS and press Next
8 Load RAID Drivers ▼

At the "Where do you want to install Windows?" step, click Load driver:

  1. Click Browse in the popup
  2. Navigate to your USB stick
  3. Select the folder containing your Intel RST drivers → Press OK
  4. Press Ctrl + A to select all drivers, then click Next
9 Complete Installation ▼

Select the disk you want to install Windows on and press Next. Continue with the installation process.

10 Create Offline Account ▼

The installation process should start. Make sure to create an offline account.

⚠️
Windows 11 Users On Windows 11, creating an offline account is no longer possible through the normal setup. Either make a new Microsoft account or search YouTube for "latest offline account create method Windows 11". One workaround is to disconnect your internet once you're at that step.
11 Turn OFF Privacy Settings ▼

When prompted during setup, turn off all privacy settings before proceeding.

12 Verify Serial Changes ▼

Use Disk serial checker.exe and verify that the serials have changed. Compare old vs new serials. If disk serials remain unchanged, contact support and we will find a solution.

✅ After Reinstallation Checklist

  1. Make an offline account or a new Microsoft account. Don't log into old ones.
  2. Do not log into OneDrive, GeForce Experience, or Medal using the same account.
  3. Install VC++ Redistributable to prevent errors with applications.
